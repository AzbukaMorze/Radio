# Lo-Fi + Chill Radio (Single HTML)

Минималистичное веб-приложение для фокуса: радио, часы, помодоро и doodle-доска в одном файле.

## Что умеет
- Выбор жанра и станции (Lo-Fi, ambient, downtempo, IDM).
- Плеер через `audio` с fallback на резервный поток выбранной станции.
- Кнопка `Next Station` для быстрого переключения в рамках жанра.
- Кнопка Play/Pause и статус подключения.
- Запоминание последнего жанра и станции через `localStorage`.
- Часы и текущая дата.
- Pomodoro таймер (work/break, старт, пауза, сброс, звуки).
- Doodle canvas (цвет, толщина, очистка, экспорт PNG).
- Адаптивный интерфейс для desktop/mobile.

## Запуск
1. Открой `radioPage.html` в браузере.
2. Нажми `Play LoFi` (на мобильных аудио стартует только после тапа).

## Техстек
- HTML + CSS + vanilla JavaScript
- Без сборки и зависимостей
- Один основной файл: `radioPage.html`

## Ограничения
- Некоторые сети/VPN могут блокировать аудиопотоки.
- Если поток не доступен, плеер автоматически пробует резервный.
- Если не работает и резервный, используй кнопку `Open Station Page`.
